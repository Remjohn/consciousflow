LESSON 08 — ORCHESTRATION LAYER

Multi-Context Transfer
The 6 CCP Subsystems

A single fundamental truth (Event loop health via explicit delegation) solves completely different engineering constraints depending on the CCP subsystem you operate within.

01 — SYSTEM WIDE MAPPING

The Subsystem Tour

FastAPI Chassis

The Constraint: WebSocket connections represent real-time voice streams. Dead air breaks the psychological bridge.

The Execution: await websocket.receive().
We yield control back to the exact client endpoint only when network data arrives, allowing thousands of simultaneous live connections to multiplex over a single thread.

Sovereign QA Subsystem

The Constraint: Validating agentic payloads requires 15 concurrent LLM calls to check for hallucination, brand-voice, and logic.

The Execution: asyncio.gather(*tasks).
Instead of taking 15×2 seconds to evaluate, the QA subsystem executes all checks in exactly 2 seconds of wall-clock time by awaiting the entire batch.

The Machinist Manager

The Constraint: The Machinist must boot up worker Pi agents on the fly, via shell commands, without blocking its own supervision loop.

The Execution: asyncio.create_subprocess_exec().
The OS handles the Pi subprocess execution while the Machinist listens for health-check signals via async pipes.

Pi Robot Arm (ElevenLabs)

The Constraint: Audio bytes from TTS arrive in chunks, not all at once.

The Execution: async for chunk in tts.stream():.
The loop yields control while waiting for the next TCP packet of audio to arrive, allowing the pipeline to process earlier chunks instantly.

Neo4j Memory Engine

The Constraint: Writing the finalized coaching transcript to the graph database post-call.

The Execution: asyncio.create_task(db.write()).
Fire-and-forget. We don't await the result. The task operates in the background, allowing the websocket to cleanly disconnect without making the client wait for database I/O.

Skill Compiler (DSPy)

The Constraint: Extensive CPU-bound prompt optimization via synthetic data generation.

The Danger: CPU-bound tasks (math, deep parsing) do not benefit from async and will starve the loop. They must be exiled using loop.run_in_executor() or run in a separate synchronous worker process.

02 — CROSS-CONTEXT INVARIANTS

The "Cost of Ignorance" Matrix

If Chassis ignores Async

Capacity drops from 2,000 WebSocket users to exactly 1. The entire platform queues sequentially behind the slowest speaker.

If QA ignores Async

Validation takes 30 seconds instead of 2. The pipeline latency exceeds the human conversational threshold. The product fails.

If Memory Engine ignores Async

The client experiences an artificial 3-second delay when attempting to end the call, because the server makes them wait while Neo4j writes data to disk.
