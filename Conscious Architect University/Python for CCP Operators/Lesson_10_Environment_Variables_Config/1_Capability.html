02 — THE SOURCE CODE

Minimal Code Readings

The Hard Requirement

import os

# Reading guardrail timeout
pi_timeout_str: str = os.environ["RLM_TIMEOUT"]
pi_timeout: int = int(pi_timeout_str)

Behavior: Strict dictionary accessor os.environ["KEY"]. If the value isn't there, the factory shuts down immediately with a KeyError rather than operating unpredictably. Fail fast.

The Graceful Fallback

import os

# Active model routing
active_model: str = os.environ.get("RLM_CHILD_MODEL", "qwen-3.5")

# Extract threshold
cbcs_str: str = os.environ.get("CBCS_THRESHOLD", "0.85")
cbcs_val: float = float(cbcs_str)

Behavior: .get("KEY", "default") allows the Architect to provide a safe, predetermined fallback. The platform continues to operate without crashing.

The Boolean Trap

import os

# Check debug mode
is_debug: bool = bool(os.environ.get("CCP_DEBUG", ""))

Behavior: Environment variables are ALWAYS strings. The string "False" is not empty, and bool("False") evaluates to True. You must explicitly parse string content: if os.environ.get("...") == "True".
