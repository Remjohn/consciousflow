What This Layer Does

Applying the QA Inspector (Pydantic)

If Python ignores type hints natively, why do we use them? Because another system—The QA Department (Pydantic)—reads the hints and enforces them before logic runs.

class CoachingState(BaseModel):
session_id: int

state = CoachingState(session_id="URGENT")
