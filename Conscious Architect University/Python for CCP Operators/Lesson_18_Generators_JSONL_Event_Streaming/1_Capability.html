Stage 2 of 8 — Architectural Definition

The Conveyor Belt vs the Locked Room

The return statement builds a locked room: all data accumulates inside the function, invisible, until the door opens at the end. The operator is locked out.

The yield keyword breaks the door open. Instead of hoarding all events until completion, yield hands each event to the caller the millisecond it is produced — then pauses, preserving all internal state, waiting to be asked for the next event.

return (Locked Room)

Process everything → store in memory → door opens → dump everything at once.

Operator: blind for 44 seconds → assumes crash → kills agent.

yield (Conveyor Belt)

Process one event → hand it immediately → pause → next event → hand it → repeat.

Operator: live telemetry every step → maintains control → can override if needed.

Factory Floor Metaphor: The generator is the Robot Arm's live camera feed. `return` is shipping everything in a sealed box. `yield` is a live camera transmitting every weld, every pick, every placement in real-time. The Foreman supervises — not guesses.
JSONL is the cargo format on the conveyor. Each item must be a standalone, complete JSON object terminating with a newline \n. If a package arrives without a seal, the receiving parser cannot tell where it ends.

What does yield change?

import json

def stream_history(client_id: str):
    yield json.dumps({"status": "fetching_transcripts"}) + "\n"

    # ... 29 seconds of LLM work ...

Stage 6 of 8 — Factory Floor & Consequence Map

Where This Sits in the Sovereign Stack

The Robot Arm (Pi Harness) executes commands. The Chassis (FastAPI) routes requests. Between them, the generator stream is the telemetry umbilical. yield + JSONL is what makes the Robot Arm visible to the Foreman in real-time.
Pi Harness → yield JSONL → FastAPI StreamingResponse → encode bytes → WebSocket → Client UI

Consequence Map — What breaks when this is wrong

1. Missing \n → Two JSON payloads fuse into one unparseable string → Frontend JSON.parse throws → WebSocket severs → client disconnects mid-session. (Pi Harness JSONL Protocol)
2. Using return instead of yield → Operator sees no output for 45 seconds → assumes crash → kills process → agent destroyed 3 seconds before completion. (Building Effective Terminal Agents, 190/200)
3. Consuming generator twice → First consumer exhausts the pipeline → second consumer gets empty stream → FastAPI delivers empty response → client receives zero events. (Orchestration Dichotomy, Dictum 1)
