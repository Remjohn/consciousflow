01 — Universal Mapping

The 6-Subsystem Tour

🏗️ The Chassis — FastAPI Route

Unique Insight: The Chassis does not generate or validate data — it routes it. The generator here is an async adapter translating between the internal Pi Harness stream and the external HTTP network protocol.

async def event_generator(): async for raw_line in harness.run_session(session_id): yield raw_line.encode("utf-8") # bytes for network return StreamingResponse( event_generator(), media_type="application/x-ndjson" )
Architectural Role: Transport bridge — converts Python generator protocol to HTTP stream bytes. Without this, the Pi Harness stream never leaves the server process.
If removed: The endpoint returns synchronously — client waits for the entire session to complete before receiving a single byte. 45-second UI freeze.

📋 QA Department — Pydantic Intercept

Unique Insight: Here the generator is a filter. It consumes a raw stream and only emits lines that pass schema validation. It is a transparent proxy — valid events flow through unchanged; invalid events are blocked or converted to error lines.

def validated_stream(raw: Generator) -> Generator: for line in raw: try: TelemetryEvent.model_validate_json(line) yield line # pass-through if valid except ValidationError as e: yield json.dumps({"type": "error", "msg": str(e)}) + "\n"
Architectural Role: Schema enforcement gateway. Every event is inspected before being forwarded. Hallucinated event types never reach the client UI.
If removed: Schema-drift propagates silently. The React frontend receives unrecognised event_types and renders blank components — invisible failures during live client sessions.

⚙️ The Machinist — DSPy Pipeline

Unique Insight: Here the generator enforces cognitive window management. DSPy can only optimise effectively on atomic inputs. Streaming forces each session through individually, preventing context window overflow and maintaining compilation fidelity.

def dspy_synthesis_stream(cursor) -> Generator: synthesizer = dspy.Predict(SessionSynthesisSignature) for transcript in cursor: # one session at a time result = synthesizer( session_transcript=transcript ) yield result.psychological_vector + "\n"
Architectural Role: Cognitive isolation boundary. Forces the LLM to reason about one context unit at a time. Yields the distilled insight before loading the next session.
If removed: 50 transcripts loaded as one massive prompt → exceeds token limit → DSPy raises ContextWindowError → entire synthesis fails with zero output.

🤖 The Robot Arm — Pi Harness

Unique Insight: Here the generator connects operating system stdout to the sovereign telemetry pipeline. Each line the LLM subprocess prints to terminal becomes a structured, validated JSONL event visible to the Foreman in real-time.

def pi_shell_stream(cmd_seq: list[str]): proc = subprocess.Popen(cmd_seq, stdout=PIPE, text=True) for line in iter(proc.stdout.readline, ""): event = {"bash_out": line.strip(), "pid": proc.pid} yield json.dumps(event) + "\n" proc.wait()
Architectural Role: Operating system telemetry bridge. Translates raw shell output into structured, labelled JSONL events with PID tracking for process accountability.
If removed: subprocess runs in silence. Long-running bash commands become unmonitorable. The Foreman kills the process on timeout — destroying multi-minute synthesis operations.

🧠 The Memory Engine — Neo4j Graph

Unique Insight: Here the generator manages database cursor exhaustion. A Neo4j query cursor yields rows on demand — the generator maps each row to a JSONL line without ever loading the full result set into Python memory.

def graph_context_stream(driver, client_id: str): with driver.session() as db: result = db.run( "MATCH (c:Client {id:$id})-[:SESSION]->(s) RETURN s", id=client_id # parameterised — no injection ) for record in result: yield json.dumps(record.data()) + "\n"
Architectural Role: Database-to-stream adapter. The cursor is itself lazy — it fetches rows from Neo4j on demand, which the generator immediately yields downstream, maintaining end-to-end laziness.
If removed (list comprehension): All graph nodes loaded into Python RAM simultaneously. At 1,000 sessions of 8KB each = 8MB per client. At 200 concurrent users = 1.6GB RAM spike → OOM container kill.

🎯 The Skill Compiler — JIT Voice DNA

Unique Insight: Here the generator enables progressive persona assembly. Voice DNA traits are compiled and injected one fragment at a time, allowing the agent persona to shift mid-session based on incoming telemetry — without stopping the session to reload the full profile.

def voice_dna_compiler(trait_queue: list[str]): for trait in trait_queue: fragment = ( f"When coaching, you embody the trait: {trait}. " "Apply it at every response boundary." ) yield json.dumps({"dna_fragment": fragment}) + "\n"
Architectural Role: Modular persona injection pipeline. Each trait fragment is compiled individually, allowing real-time persona layering without halting execution to reconstruct the full Voice DNA string.
If removed: Full persona must be compiled before the session begins. Dynamic mid-session trait adaptation becomes impossible. Persona is static for the entire session duration.

02 — Fidelity Spectrum

Cross-Context Comparison

🏗️ Chassis vs 📋 QA Dept

Same pattern, different purpose. Chassis uses the generator as a byte-level transport bridge (encoding strings to bytes). QA uses it as a filtering proxy (validating and potentially blocking events). Both consume one stream and yield to the next layer — but one transforms format, the other enforces contracts.

⚙️ Machinist vs 🧠 Memory Engine

Same memory goal, different source. Both achieve O(1) memory footprint — but Machinist controls LLM cognitive load (one prompt context at a time), while Memory Engine controls Python RAM (one cursor row at a time). Machinist manages AI bandwidth; Memory Engine manages hardware capacity.

🤖 Robot Arm vs 🎯 Skill Compiler

Same emission cadence, different source. Robot Arm streams from an external OS subprocess (output determined by the shell). Skill Compiler streams from an internal data queue (output determined by the persona design). One reads — one generates. Both yield structured JSONL at atomic granularity.

The Universal Principle: Across all 6 contexts, yield + \n achieves one of three goals: (1) live observability for the Foreman, (2) memory efficiency on constrained infrastructure, or (3) cognitive isolation for AI pipeline integrity. Often all three simultaneously.
