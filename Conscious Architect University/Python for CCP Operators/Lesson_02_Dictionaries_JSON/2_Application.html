from pydantic import BaseModel, Field

class SessionStateContract(BaseModel): coach_id: str = Field(..., description="Instance ID") client_state: dict = Field(default_factory=dict) cbcs_score: float = Field(..., ge=0.0, le=1.0)
Context: Inheriting from BaseModel morphs our class into a highly enforced Dictionary structure.
Ingestion: Pydantic receives an untyped dictionary created from an incoming JSON string.
Validation 1: Verifies the `coach_id` key exists and its value is strictly text (string).
Validation 2: Requires `client_state` to be a nested dictionary structure. Automatically injects `{}` if missing.
Validation 3: Math constraints. The float value MUST be between 0.0 and 1.0. If the LLM returned `1.5`, the conversion crashes here.
Orchestration Dichotomy Mapping: If this dictionary validation is removed, the laser cutter (LLM) gains the ability to write direct, unverified logic to the Chassis. The factory turns into a hallucination spiral.
