The Chassis — FastAPI Routing Laws

FastAPI uses decorators to route HTTP traffic. But more importantly, we stack our custom CCP decorators above the route decorator to intercept unauthorized access before FastAPI even builds the request object.

@require_role("SUPER_ADMIN") @app.delete("/system/cache/flush") async def flush_redis_cache(user = Depends(get_current_user)): redis_client.flushall() return {"msg": "Catastrophic flush complete."}
