Chassis (FastAPI Router)

The entry point. Ensures external reality (HTTP requests) conforms to system expectations before interacting with deeper logic.

@app.post("/ingest")
def route_payload(data: dict) -> dict:
    # Blocks all non-JSON requests at the door
    return process(data)

What if we remove this signature?

Someone hits `/ingest` with an MP4 video file.

QA Dept (Pydantic Validation)

The gatekeeper. Enforces the exact internal shape of data that the pipeline requires.

class AnalysisSchema(BaseModel):
    threat_level: int
    description: str

What if we remove this signature?

The LLM decides to output `threat_level: "High"` instead of `5`.

Machinist (DSPy LLM Boundaries)

The executor. Replaces fragile prompt engineering with rigid structural contracts.

class GenerateSummary(dspy.Signature):
    text = dspy.InputField()
    summary = dspy.OutputField()

What if we remove this signature?

We use a custom, untyped prompt instead.

Robot Arm (Subprocess / Tools)

Physical action. A function that runs a script or API but yields nothing.

def trigger_webhook(url: str) -> None:
    # Fires network request. Leaves no trace.
    requests.post(url)

What if we remove this signature?

Another developer tries to catch a response from this function.

Memory Engine (Neo4j / Graph)

State persistence. The function signature defends the permanent graph architecture.

def store_node(node_id: str, properties: dict) -> bool:
    # Ingestion logic
    return True

What if we remove this signature?

A poorly formatted integer ID is passed into Neo4j.

Skill Compiler (JIT Execution)

The highest abstract logic. Compiling code structurally requires explicit contracts.

def generate_skill_code(objective: str) -> str:
    # Generates Python code
    return compiled_string

What if we remove this signature?

The system accidentally returns a compiled functional object instead of a string.
