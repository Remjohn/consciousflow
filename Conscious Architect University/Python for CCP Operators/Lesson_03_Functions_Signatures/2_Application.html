Framework 3: The LLM Contract

DSPy Signatures

DSPy takes the function signature concept and scales it directly to Large Language Models. In DSPy, the signature replaces the prompt. It enforces input strings and forces output structures without writing rules.

import dspy

class GenerateTweet(dspy.Signature):
    """Convert a raw concept into a high-engagement tweet."""
    raw_concept = dspy.InputField(desc="unstructured idea")
    tweet_text = dspy.OutputField(desc="max 280 chars")
