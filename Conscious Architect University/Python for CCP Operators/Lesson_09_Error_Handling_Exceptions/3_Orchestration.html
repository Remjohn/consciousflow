Cross-Context Reflection

The role of exceptions morphs depending on the proximity to the Stochastic boundary (LLM):

  • Boundary Form: FastAPI is the outermost boundary, so its error handling must be forgiving and opaque (HTTP 500). The JIT compiler is the deepest engine, so it must be rigid and transparent (CompilationError).
  • Defensive Stance: The Pi Harness uses exceptions to defend the system from death (timeout loops). Neo4j uses exceptions to defend the data from corruption (transaction rollbacks).
  • Contract Stance: Pydantic treats an exception as a Terminal Breach of Contract. DSPy treats an exception as an Instructional Dialogue for the retry loop.
