Lesson 09 - Capability Layer

An Exception is the Emergency Stop Button.

Without error handling, a single hallucinated JSON string or network lag permanently kills the OODA loop. It turns your deterministic factory into a fragile house of cards.

The Chassis Failure

If the Qwen-3.5 72B reasoning model forgets a closing bracket } in its JSON output, json.loads() triggers a fatal crash. The session ends instantly for the client.

The Strategic Fix

Exceptions allow you to decouple the "happy path" from the "failure path". It builds an impenetrable quarantine wall to divert defects into a Routing Chute instead of stopping the assembly line.

Scenario 1 of 3: The Defect

The Basic Try/Except Block

A corrupted payload is entering the deterministic orchestrator. Look at the code below.

import json

raw_response = '{"trigger": "humor"' # Notice: Missing closing bracket }

try:
    state = json.loads(raw_response)
    print("State loaded successfully.")
except json.JSONDecodeError:
    state = {"trigger": "fallback"}
    print("Defect caught. Fallback deployed.")

print(state["trigger"])

Scenario 2 of 3: The Explicit Alarm

Intentional Triggers & The Factory Janitor

We are manually raising an alarm when an invariant fails, and providing cleanup logic.

def validate_cbcs(score):
    try:
        if score > 1.0:
            raise ValueError("Score too high")
        return True
    except ValueError as e:
        print(f"Validation failed: {e}")
        return False
    finally:
        print("Inspection completed.")

validate_cbcs(1.5)
