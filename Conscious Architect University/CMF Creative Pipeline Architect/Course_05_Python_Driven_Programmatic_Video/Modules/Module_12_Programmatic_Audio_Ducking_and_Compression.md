## Phase III: First Principles, Lexicon & Systems Engineering
To the Conscious Architect, audio is not a "vibe"—it is a **Numpy array of floats**. At its most primitive level, digital sound is simply a list of numbers representing the intensity of air pressure (amplitude) at a specific point in time. If a sound is recorded at 48kHz, there are 48,000 of these numbers per second. 

**THE TECHNICAL LEXICON (MANDATORY):**
- **Side-chaining:** A process in which the effect on one signal (the music) is triggered by the presence of a completely different signal (the voiceover). It is a "social" interaction between two isolated data streams.
- **Envelope Detection:** The mathematical extraction of a "smoothed" boundary (the envelope) of a volatile audio signal. It turns chaotic peaks into a stable control curve.
- **Gain:** The multiplication ratio of a signal's amplitude. A gain of `1.0` is original volume; `0.5` is half-volume; `0.0` is silence.
- **Clipping:** A catastrophic failure where the amplitude exceeds the maximum numerical range (usually `1.0` to `-1.0`), resulting in the digital "chopping" of the wave—the auditory equivalent of looking at the sun.

In systems engineering terms, programmatic ducking is a **Relational Feedback Loop**. We are creating a bridge where the state of `Component A` (Voiceover) dictates the operational threshold of `Component B` (Music). In **FFmpeg 8.0 ("Huffman")**, which we leverage as our backend engine, this is handled by the `sidechaincompress` filter. However, to truly architect the CMF, we must understand the logic underneath. 

When the voiceover enters a specific time coordinate, its amplitude increases. We detect this peak, calculate a "Duck Factor," and apply it as a scalar multiplier to the music track’s array in the same coordinate. It is pure, index-locked mathematics. There is no guessing. If the voice is there, the music is lowered by exactly the X-percent defined in our JSON configuration.

## Phase V: Python Native Construction
We will now implement a deterministic ducking algorithm using Python Difficulty Tier 4 logic. We will focus on **Array Manipulation**, as sound is fundamentally an array of amplitude values.

**THE PYTHON DEFINITION RUBRIC (MANDATORY):**
- **What is an Array?** Think of an array as a long, numbered row of lockers. Each locker holds a single number (the amplitude at that microsecond). To "see" a sound, we look at thousands of lockers at once.
- **What is Scalar Multiplication?** Imagine you have a list of numbers: `[10, 20, 30]`. If you multiply it by a "scalar" of `0.5`, every number in the list is cut in half: `[5, 10, 15]`. This is how we lower volume—we multiply every "locker" in the music array by a decimal value like `0.3`.

import numpy as np

# CCP-Native Component: AudioDuckingEngine
# This script simulates the logic used to ensure MOSS-TTS clarity over B-Roll music.

def apply_programmatic_ducking(voice_array, music_array, threshold=0.1, duck_factor=0.3):
    """
    Implements a deterministic side-chain ducking logic.
    Whenever voice_array[index] > threshold, music_array[index] is multiplied by duck_factor.
    """
    
    # In the CMF, both arrays must be synchronized (same length/sample rate).
    if len(voice_array) != len(music_array):
        # We don't guess in the CMF. We fail and log.
        raise ValueError("Auditory Array Desynchronization Detected. Check Pipeline Master Clock.")

    # We iterate through the 'lockers' (samples) of the audio arrays.
    # Note: In a real CMF production environment, we use vectorized numpy math 
    # for speed, but here we use a loop to show the First Principle logic.
    
    ducked_music = np.copy(music_array)
    
    # Phase III: Logic Mapping
    for i in range(len(voice_array)):
        # Calculate the absolute amplitude (absolute value removes negative wave peaks)
        amplitude = abs(voice_array[i])
        
        # Phase IV: The Hydraulic Valve Trigger
        if amplitude > threshold:
            # The 'Pressure' is high enough to choke the Music Pipe.
            ducked_music[i] = music_array[i] * duck_factor
        else:
            # The 'Voice Pipe' is empty; the Music Pipe stays at full pressure (1.0x).
            ducked_music[i] = music_array[i] * 1.0
            
    return ducked_music

# Music: [Full, Full, Full, Full, Full]
