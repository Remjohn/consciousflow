02 — MATRICES ENCODE GEOMETRY

How Matrices Reshape Space

Diagonal (Scaling)

[s₁ 0] · v = [s₁v₁]
[0 s₂]     [s₂v₂]

Each axis scaled independently. In Transformers: amplifying or dampening specific feature dimensions.

Rotation

[cosθ -sinθ]
[sinθ  cosθ]

Norm-preserving. Paper #35's steering technique: rotate the hidden state's direction without changing its magnitude.

Projection

[1 0] · v = [v₁]
[0 0]     [0 ]

Information destruction. Q/K/V projections: 768→64. 704 dimensions permanently annihilated per head.

LoRA Update

ΔW = B(768×16) · A(16×768)
rank ≤ 16

Low-rank factorization. Only 16 independent directions modifiable. 752 directions frozen. Sufficient for Voice DNA (~8-12D), fails for reasoning (>64D).

03 — THE RANK BOTTLENECK

LoRA: Low-Rank Adaptation

Instead of modifying the full 768×768 weight matrix (589,824 params), LoRA factorizes the update as ΔW = B × A through a rank-r bottleneck.

Rank 16
Paper #31: Voice DNA has intrinsic dimension ~8-12. Rank 16 is sufficient. Complex reasoning has dimension >64 — LoRA catastrophically fails.

04 — EDGE CASES

Extremes & Shape Rules

Identity Matrix

I·v = v. The pass-through. Residual connections effectively add an identity: output = Ix + T(x) = x + T(x).

Zero Matrix

0·v = 0. Total information annihilation. A dead attention head with collapsed weights.

Non-Square: Dimension Change

64×768 = compression (info destroyed). 3072×768 = expansion (info preserved, higher canvas). The Transformer's compress-then-expand architecture.

Non-Commutativity

AB ≠ BA. Rotate-then-scale ≠ scale-then-rotate. In a Transformer, layer order defines the computational pipeline.
