01 — UNIVERSAL MAPPING

The 6-Domain System

Tactical Playbook as Matrix

Each row = one output behavioral stat recipe. Barella's raw stats (8,7,6,7) on [Spd, Pass, Tack, Vis]:

Sprint = 1.5(8)+0(7)+0(6)+0.2(7) = 13.4
Defense = 0.3(8)+0(7)+1.2(6)+0(7) = 9.6
Creative = 0(8)+0.8(7)+0(6)+1.0(7) = 12.6

3×4 matrix → 4D input → 3D output. The playbook compresses raw attributes into behavioral dimensions. LoRA mid-season: adjust 2 tactical principles (rank-2 update) instead of rewriting all 12 entries.

Break: Real tactics involve morale, fatigue, opponent adaptation — non-linear dynamics a static matrix cannot capture.

Dual-Class Composition

M_Warrior = diag(2.0, 1.5, 0.3)
M_Mage   = diag(0.3, 1.0, 2.0)
Battlemage = M_Mage × M_Warrior
= diag(0.6, 1.5, 0.6)

Warrior boost cancelled by Mage suppression on STR. Mage boost cancelled by Warrior suppression on INT. The Battlemage is a Dexterity-focused hybrid — neither strong nor intelligent.

Non-commutativity: For non-diagonal class matrices with cross-stat effects, Warrior→Mage ≠ Mage→Warrior.

EQ Chain as Matrix Composition

Warm EQ = diag(1.5, 1.2, 0.8, 0.5)
Vocal (3,5,7,4) → (4.5, 6.0, 5.6, 2.0)
Bass boosted, treble cut → warmer sound

If one diagonal entry is zero (Sub cut completely), that band enters the null space. No downstream EQ can recover it.

Break: Only EQ is linear. Compression, reverb, distortion generate new content the matrix model cannot represent.

Nutritional Matrix

2 eggs, 3 bread, 1 butter → v=(2,3,1)
Cal = 70(2)+80(3)+100(1) = 480
Pro = 6(2)+3(3)+0.1(1) = 21.1g
Fat = 5(2)+1(3)+11(1) = 24g

LoRA: Swap regular bread for protein bread + reduce butter = rank-2 update to the nutritional matrix. Most entries unchanged.

Break: Maillard reactions create caloric compounds not present in raw ingredients. Chemistry is non-linear.

Environmental Transformation

M_work · (C=6, E=8, N=7) =
C_out = 1.5(6)+0.2(8) = 10.6 ← cross-term!
E_out = 0.1(6)+0.8(8) = 7.0
N_out = 0.4(7) = 2.8 ← suppressed

Off-diagonal entries model cross-trait interactions: social accountability (E) drives diligence (C). Party→Work composition produces different behavior than Work→Party.

Break: Extreme stress triggers qualitative shifts (fight-or-flight) that cannot be modeled as linear scaling.

Weight Matrices as Learned Transformations

3.5B parameters across hundreds of matrices. "Overwhelmed" passes through W_Q → W_K → W_V → W₁ → W₂. Each multiplication reshapes the 768D embedding into specialized representations.

LoRA on W_Q,K,V,O → Voice DNA (rank 16)

02 — FIDELITY SPECTRUM

Cross-Domain Comparison

🤖 AI & 🎵 Audio

Exact. GPU executes matrix multiplication literally. EQ is rigorous linear spectral operation.

⚽ Sports & 🍳 Cooking

Proportional. Double eggs → double protein. But Maillard reactions and player morale are non-linear.

🧠 Psychology & 🎮 Gaming

First-order. Cross-trait modulation captured, but feedback loops, caps, and threshold effects break linearity.

Analogy Failures: (1) "Multiplication = scaling" — matrix mult is transformation execution, not making bigger. (2) "More params = more capability" — LoRA proves 4% suffices for style. (3) "Order doesn't matter" — AB ≠ BA almost always.

03 — REASONING TRAPS

Logic Puzzles

1. The Shape Trap

Setup: A ∈ ℝ³ˣ⁴, B ∈ ℝ⁴ˣ². Is AB defined? Is BA defined?

AB: (3×4)×(4×2) → 3×2. ✓ Inner dims match. BA: (4×2)×(3×4). Inner dims 2≠3. ❌ Undefined. Non-commutativity is sometimes forced by shape incompatibility.
2. The Rank Paradox

Setup: rank(A) = 3, rank(B) = 50. Maximum rank of AB?

rank(AB) ≤ min(3, 50) = 3. The rank-3 factor bottlenecks everything. No matter how expressive B is, composition through a rank-3 bottleneck = 3 directions max. This IS LoRA's constraint.
3. The Identity Composition

Setup: M × I = ?

MI = M. The identity is "do nothing." The residual connection adds I·x alongside T(x), providing a bypass that preserves the original signal.
4. The Null Space Cascade

Setup: A has 200D null space. B has 100D null space. Min null space of AB?

At least 200. B's null space (100D) feeds zero into A. Plus everything B maps INTO A's null space (200D) is also annihilated. Information destruction cascades — each transformation can only maintain or increase total destruction.

04 — KINESTHETIC TASK

Build-Your-Own Matrix

Compression: A matrix is a frozen transformation. Multiplying is executing it. Chaining is composing them. Rank is the ceiling on what it can express.
