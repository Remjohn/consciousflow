The Grain of the Wood

Every woodworker knows: wood has a grain. Cut with the grain and the blade slides effortlessly — the wood splits along its natural direction. Cut against it and you fight the material. The blade catches, the wood splinters, the cut is jagged and ugly.

The grain is the wood's eigenvector. It is the direction where the material's response is pure — simple, predictable, efficient. Every other direction produces a complex, mixed response: splitting, splintering, and tearing in unpredictable combination.

Linear transformations have a grain too. A matrix acting on most vectors rotates them — shears, stretches, mixes them asymmetrically. But there are special directions where the matrix's action is pure: the output is parallel to the input. No rotation. No mixing. Just scaling. These special directions are eigenvectors. The scaling factor along each is the eigenvalue.

The defining equation: Av = λv — apply transformation A to vector v, and the result is v itself, scaled by λ. Direction unchanged. Only magnitude changes.

Trap 01 — The Matrix Response
Apply the transformation matrix A = [[3, 1], [0, 2]] to the vector v = [1, −1].

Does the output vector rotate away from its original direction, or does it keep pointing along the exact same line?

You have found an eigenvector. The vast majority of inputs fed to A would be rotated into completely new orientations. But [1, −1] is perfectly aligned with one of this matrix's natural "grain" directions — multiplication merely doubled its length.

The two eigenvectors of this matrix are [1, 0] (eigenvalue = 3) and [1, −1] (eigenvalue = 2). Every other direction is a mixture of these two and gets rotated when processed.

Why Eigenvectors Simplify Everything

You might think: "So some vectors don't rotate. Why should I care?" Because the eigenvector basis diagonalizes the matrix — and a diagonal matrix is the simplest matrix that exists.

Express any matrix in its eigenvector basis and you get: A = PDP⁻¹, where D is a diagonal matrix containing only the eigenvalues on the main diagonal and zeros everywhere else. In the eigenvector basis, every dimension is independent — dimension 1 scales by λ₁, dimension 2 scales by λ₂. No mixing. No coupling. No cross-dimensional effects.

This has direct operational consequences. Computing A¹⁰⁰ normally requires 99 matrix multiplications. In the eigenvector basis: D¹⁰⁰ = diag(λ₁¹⁰⁰, λ₂¹⁰⁰) — just raise each eigenvalue to the 100th power. Done.

More critically: stability analysis. If all |λᵢ| < 1, repeated application of A shrinks everything to zero — the system is stable. If any |λᵢ| > 1, the system explodes along that eigenvector.

Trap 02 — Gradient Stability
During backpropagation through a Transformer, the gradient signal is multiplied by each layer's weight matrix transpose at every layer.

If the eigenvalues of these weight matrices are consistently greater than 1 across many layers, what happens to the gradient signal?

The gradient explodes when eigenvalues are consistently above 1 — each layer multiplies the signal by a factor > 1, so across N layers the gradient grows as λᴺ → ∞. This is why careful initialization, LayerNorm, and residual connections in Transformers are engineered to keep eigenvalues near 1.

The reverse is also dangerous: eigenvalues consistently below 1 cause the gradient to vanish — it decays to zero and early layers receive no learning signal. Both failure modes are pure eigenvalue phenomena.

No eigenvalue dominates → this head spreads attention across many tokens. It computes a broad weighted average — a "context summarizer" that aggregates emotional tone across the whole conversation.

HeadKV (Paper #46) uses this distinction operationally: sharp-spectrum heads are CRITICAL for reasoning and are protected. Flat-spectrum heads are REDUNDANT and are compressed during KV cache optimization for long sessions.

Trap 03 — Head Classification
HeadKV compresses a KV cache for a long Roleplay session. A head has eigenspectrum: [0.91, 0.04, 0.03, 0.02].

Should HeadKV protect this head's KV cache (keep full precision) or compress it?

A spectrum of [0.91, 0.04, 0.03, 0.02] is sharply dominated by one eigenvalue — this is a Focused Retriever. It deterministically routes specific, high-impact information. Evicting its KV cache would destroy that specific retrieval path. HeadKV protects it.

The flat-spectrum heads — those with eigenvalues like [0.28, 0.26, 0.24, 0.22] — are broad integrators. Their averaged output can be approximated cheaply. Those get compressed.

Rogue Scalpel — Adversarial Attacks Along Eigenvectors

An adversarial attack seeks to change the model's behavior using the smallest possible input perturbation. Where should the attacker aim?

Along the dominant eigenvector of the Value projection W_V.

The Value projection determines what information each token contributes to the attention output. Its dominant eigenvector is the direction of maximum sensitivity — a perturbation along this direction produces the largest possible change in attention output per unit of perturbation magnitude.

If the dominant eigenvector of a Thinking Sparks head aligns with "coaching tone," then a tiny perturbation along this eigenvector could flip the coaching agent from empathetic to aggressive — with minimal detectable input change.

The Guardian Agent defense counters this: pre-compute the dominant eigenvectors of each critical head's W_V; for each incoming prompt, project it onto these eigenvectors; if any component is anomalously large, flag the prompt. This is an eigenvalue-based anomaly detector.

Trap 04 — Maximum Vulnerability Direction
An adversary wants to maximally disrupt a coaching model with the smallest possible perturbation.

In which mathematical direction should they inject the perturbation to maximize their damage per unit of perturbation magnitude?

The dominant eigenvector of W_V is the direction of maximum amplification. A unit-length perturbation along this direction produces the largest possible change in output — because the eigenvalue is the amplification factor, and the dominant eigenvalue is the largest one. The adversary is exploiting the same grain-of-the-wood phenomenon: maximum effect for minimum effort.

The smallest eigenvector is the direction the head ignores — a perturbation there causes near-zero change in output. That would be the wrong target.
