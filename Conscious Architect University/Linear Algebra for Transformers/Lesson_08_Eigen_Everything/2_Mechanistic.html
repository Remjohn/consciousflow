Formal Definitions

The eigenvalue equation is Av = λv. For this to have a non-trivial solution (v ≠ 0), the matrix (A − λI) must be singular — it must collapse space, meaning its determinant equals zero:

det(A − λI) = 0

This determinant expands into a polynomial in λ — the characteristic polynomial. Its roots are the eigenvalues. Once eigenvalues are known, substituting each back into (A − λI)v = 0 gives the corresponding eigenvectors.

If a matrix has n linearly independent eigenvectors, it can be diagonalized: A = PDP⁻¹, where P's columns are eigenvectors and D is diagonal with eigenvalues on the main diagonal. In this eigenvector basis, A IS D — pure independent scaling with zero cross-dimensional mixing.

Singular Value Decomposition (SVD)

Eigenvalue decomposition requires a square matrix. But attention projections like W_Q ∈ ℝ^(d_k × d) are non-square. The generalization is SVD:

W = U Σ Vᵀ

Where: U contains the left singular vectors (eigenvectors of WWᵀ), Σ is diagonal with singular values σᵢ = √λᵢ(WᵀW), and V contains the right singular vectors (eigenvectors of WᵀW). The singular values measure how much W stretches along each orthogonal direction.

LoRA connection: LoRA's rank-r approximation keeps only the top r singular values. If the singular values decay rapidly (a few large, then near-zero), the matrix is effectively low-rank — LoRA with r=4 or r=8 captures nearly all behavior. If the singular values are all similar (flat spectrum), the matrix is truly high-rank and LoRA will lose significant information.

Hessian Eigenvalues — Learning Rate Safety

The Hessian H is the matrix of second-order loss derivatives. It is symmetric, so all eigenvalues are real (Spectral Theorem). Hessian eigenvalue interpretation:

  • λᵢ > 0 → loss curves UPWARD in direction vᵢ (local minimum along this axis)
  • λᵢ < 0 → loss curves DOWNWARD (local maximum — saddle point)
  • λᵢ = 0 → flat — loss is insensitive to movement along this axis

Maximum safe learning rate: η_max = 2 / λ_max(H)

Exceeding this threshold causes oscillation and divergence along the sharpest curvature direction. This is the eigenvalue-based explanation for gradient explosion from Lesson 11.
