01 — ATTENTION = LEARNED SUBSPACE PROJECTION

Q/K/V as Projection Operators

Each attention head learns three different 64D subspaces to project the 768D embedding onto. Then it computes dot products between the projected vectors.

W_Q → "Search" Subspace

Projects onto what this token is looking for. 768D → 64D. 704 dimensions annihilated.

W_K → "Identity" Subspace

Projects onto what this token offers to be found. Same dimensionality compression.

W_V → "Extraction" Subspace

Projects onto the content this token contributes to blended outputs.

The dot product Q·Kᵀ computes alignment between vectors that have already been projected. The head ignores 704 dimensions of noise — isolating the 64 dimensions that matter.

PAPER #27: CASAL

Hallucination Detection

Find the hallucination direction: d_hall = mean(h_hallucinated) − mean(h_grounded). At generation time, project h_t onto d_hall.

Risk = h_t · d_hall / ‖d_hall‖²
Long shadow → high hallucination risk

Amortization trick: pre-compute a single projection matrix P_hall from the context window.

04 — INVARIANTS & EDGE CASES

Core Laws

Idempotency: P² = P

Project the shadow again → nothing changes. Once flattened against the wall, re-flattening is a no-op.

Residual Orthogonality

A⊥ · B = 0. Guaranteed zero overlap between residual and target direction. No signal leaks.

Pythagorean Conservation

‖A‖² = ‖proj‖² + ‖residual‖². Energy is perfectly conserved across the split.

Non-Linear Manifolds

If "Sarcasm" curves through 768D space, linear projection captures only the first-order tangent. Works well for most concepts, breaks on hyper-entangled semantics.
