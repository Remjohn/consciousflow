§ 02

Why Component-Wise Arithmetic?

Addition is not arbitrary. Every vector is a linear combination of orthogonal basis vectors. This structure makes component-wise operations an inescapable mathematical consequence — not a design choice.

Animated Decomposition: v = 4e₁ + 7e₂ + (−2)e₃
⚡ Key insight: Because e₁, e₂, e₃ are orthogonal (90° apart), adding along one axis cannot affect another. This is the geometric engine that guarantees component isolation — critical for surgical activation steering in AI.
§ 03

GPU Parallel Execution

Inside a neural network, vector addition spawns 768 simultaneous threads. Each thread blindly computes one scalar addition in complete isolation. Click to walk through the 4 steps.

768 Computational Threads — Step Through
Step 1 / 4
Memory Alignment (Dimensionality Lock)
The hardware verifies both vectors live in ℝ⁷⁶⁸. If dimensions mismatch — e.g. 768D + 512D — the operation instantly fails. There are 256 coordinates with no counterpart.
Step 2 / 4
Thread Spawning
768 isolated computational threads are instantiated simultaneously. Thread i has one job: compute cᵢ = aᵢ + bᵢ. It has zero awareness of any other thread.
Step 3 / 4
Component Isolation (Blind Execution)
Thread 5 is mathematically blind to thread 6. If steering vector b has a zero at position 6, then: c₆ = a₆ + 0 = a₆. Cross-dimensional contamination is impossible.
Step 4 / 4
Reassembly
All 768 scalar floats are written into a contiguous memory block: c = (c₁, c₂, ..., c₇₆₈). The new vector is ready for the next Transformer layer.

§ 06

High-Dimensional Behavior

In ℝ² you can draw vectors on paper. In ℝ⁷⁶⁸ human spatial intuition collapses. Random vectors become nearly orthogonal, and the Concentration of Measure warps every geometric law you know.

Dimensional Capacity vs. Model Size
Dimensional capacity grows linearly with embedding size.

⚡ Key insight: Dimensionality is not just scale — it is capacity. Each new dimension is a new degree of freedom. A 512D space physically cannot store 600 independent concepts. Raising to 768D creates 256 brand-new empty orthogonal axes.
§ 07

When Things Break

Three failure modes that corrupt vector operations inside a live Transformer:

⚡ Zero Vector
v = (0,0,...,0) has no direction and no magnitude. Attention cannot compute dot products. Token information is entirely destroyed — the model loses context at that position.
‖v‖₂ = 0 → Singularity
💥 Gradient Explosion
Components reach (99e⁶, ...). Softmax exponentiates the gap — it hardens to 1.0 for the largest token and 0.0 for everything else. The model fixates and halluccinates. Layer Norm divides by ‖v‖ to prevent this.
softmax(x→∞) → [1, 0, 0, ...]
🔀 Dimension Mismatch
Adding a 512D vector to a 768D vector is mathematically undefined. You cannot pair coordinates that have no counterpart. A projection matrix is required to up-sample or down-sample first.
ℝ⁵¹² + ℝ⁷⁶⁸ → ERROR
§ 08

Core Invariants

These laws are absolute. A system that violates them is not a vector space. Here is why each one matters for AI specifically:

L1
Commutativity — u + v = v + u
Injecting steering vectors in any order produces the same final hidden state. The sequence of interventions is geometrically irrelevant.
L2
Associativity — (u + v) + w = u + (v + w)
GPU clusters can batch-accumulate thousands of gradient updates across parallelized cores in any sequential order and get identical results. This is what makes distributed training possible.
L3
Scalar Distributivity — α(u + v) = αu + αv
Scale a combined concept, or combine individually scaled concepts — you arrive at the exact same point in high-dimensional space. The LoRA α parameter exploits this directly.
