Lesson 07 · Mechanistic Layer

The Basis Engine

Every matrix multiplication in a Transformer is a change of basis. This layer builds the derivation: from the formal definition of a basis, through the construction of change-of-basis matrices, to the exact mechanism by which attention projections and MLP layers transform representations.

I. Formal Definition

Basis

A basis for ℝⁿ is a set of n vectors satisfying two properties simultaneously:

The Two Properties

Linear independence: No vector in the set can be expressed as a linear combination of the others.
Spanning: Every vector in ℝⁿ can be expressed as a linear combination of the basis vectors.

Together, these guarantee a unique representation: for any v ∈ ℝⁿ, there exist unique coefficients c₁…cₙ such that:

Coordinate Representation
v = c₁b₁ + c₂b₂ + ⋯ + cₙbₙ
[v]_B = [c₁, c₂, …, cₙ]ᵀ  ← the coordinates of v in basis B

Change-of-Basis Matrix

Given a source basis B and target basis C, the change-of-basis matrix PB→C converts coordinates:

Core Formula
[v]_C = P_{B→C} · [v]_B

Construction: Column j of PB→C = [b_j]_C (the j-th source basis vector expressed in target-basis coordinates)

Converting FROM basis B TO standard S: Place the basis vectors of B as columns of P.

P_{B→S} Construction
P_{B→S} =
b₁ₓb₂ₓ b₁ᵧb₂ᵧ
columns = basis vectors in standard coordinates

Converting FROM standard S TO basis B: Use the inverse.

Direction Reversal
P_{S→B} = P_{B→S}⁻¹    ← this is the operation most learners apply backwards

III. Orthonormal Bases — The Computational Shortcut

A basis is orthogonal when all basis vectors are mutually perpendicular: bᵢ · bⱼ = 0 for i ≠ j. It is orthonormal when additionally each vector has unit length: ‖bᵢ‖ = 1.

Orthonormal Shortcut

For an orthonormal basis matrix Q: Qᵀ Q = I, which means Q⁻¹ = Qᵀ.
Matrix inversion is computationally expensive. Transposition is essentially free. This is why Transformer weight matrices are often initialized and regularized toward orthonormality.

IV. Basis Changes in the Transformer

Attention Projections

Each attention head performs three simultaneous basis changes:

Per Head h at Layer l
q_{l,h} = W_Q^{l,h} · h_{l−1}  W_Q ∈ ℝ^{d_k × d}
k_{l,h} = W_K^{l,h} · h_{l−1}  W_K ∈ ℝ^{d_k × d}
v_{l,h} = W_V^{l,h} · h_{l−1}  W_V ∈ ℝ^{d_k × d}

Each W matrix is a non-square projection: it maps from d dimensions to d_k dimensions (with d_k < d). These are dimension-reducing basis changes. The discarded dimensions are permanently gone.

MLP — Round-Trip Through Higher Dimensions

MLP Basis Change
MLP(h) = W₂ · σ(W₁ · h + b₁) + b₂

W₁ ∈ ℝ^{4d × d}  ↑ expands d → 4d (up-projection)
W₂ ∈ ℝ^{d × 4d}  ↓ projects 4d → d (down-projection)

The 4× expansion into higher-dimensional space provides more "room" for the nonlinearity σ to carve decision boundaries that do not exist in the lower-dimensional space. The round-trip W₂·W₁ ≠ I — the MLP is not an identity transform.

KV-Direct: The Residual Stream as Universal Basis

Since W_K is a fixed, deterministic matrix after training, knowing the residual stream h_{t} fully determines k_{l,t} for every layer l:

On-Demand Rederivation
k_{l,t} = W_K^l · h_{t}  one matrix-vector product

This enables a radical memory optimization: store only the residual stream, rederive keys and values on demand.

Standard KV Cache
24 layers × 2(K+V) × 32 heads × 128 × 2B
≈ 393 KB / token
KV-Direct
2560 × 2 bytes = residual stream only
≈ 5 KB / token (~78× compression)

The Similarity Transform

If transformation T is described in the standard basis, and you want the same transformation described in basis B:

Similarity Transform
T_B = P⁻¹ · T · P

P = change-of-basis matrix from B to standard. T itself doesn't change — only its coordinate description changes. In Lesson 8, the eigenvector basis makes every T a pure diagonal scaling matrix.
