01 — TRANSFORMER LAYER ANATOMY

Rank, Nullity, and Information Flow

The Rank-Nullity Theorem governs every projection in the Transformer: rank(T) + nullity(T) = n. Dimensions preserved + dimensions destroyed = input dimension.

W_Q: ℝ768 → ℝ64
Rank ≤ 64 (output dims)
Null space ≥ 704 (destroyed dims)
64 + 704 = 768 ✓

The Q projection necessarily destroys 704 dimensions. These are features the head cannot query — it is structurally blind to them. Different heads learn different null spaces, covering complementary views.

Feed-Forward Expansion / Compression

W₁ (768 → 3072): Injective — zero null space. No information destroyed. Creates room for GELU gating.
W₂ (3072 → 768): Null space = 2304 dims. Selectively discards features GELU deactivated.

03 — PAPER #35 + #42: SURGICAL INTERVENTION

Rotation vs Addition

ADDITIVE STEERING

h' = h + α·s

  • Changes direction AND magnitude
  • Norm distortion propagates downstream
  • Destabilizes activation statistics
  • Subject to ESR washout
PAPER #35: ROTATIONAL STEERING

‖h'‖ = ‖h‖ (norm preserved)

  • Changes direction only
  • Activation norm perfectly stable
  • Composes coherently with downstream layers
  • Resists ESR by respecting manifold geometry
PAPER #42: FRAGILE KNOWLEDGE

Width-pruning MLP columns reveals: factual knowledge is distributed (fragile, dies first) while instruction compliance is concentrated (narrow, survives pruning with +46-75% precision).

04 — EDGE CASES & INVARIANTS

Structural Laws

Residual as Immune Shield

x_next = x + T(x). Even if T washes out the steer, the residual re-adds the original steered state. A tug-of-war between ESR decay and residual preservation.

Basis Sufficiency

Know T(eᵢ) for all basis vectors → know T(v) for all vectors. This is why matrices work: the columns ARE the transformed basis vectors.

Composition Closure

T₂ ∘ T₁ is linear if both are linear. Without GELU, 24 layers collapse to 1. Non-linearity makes depth meaningful.

Rank-Nullity Conservation

rank(T) + nullity(T) = n. Information is either preserved or destroyed — never created. The null space tells you exactly what the model has chosen to ignore.
