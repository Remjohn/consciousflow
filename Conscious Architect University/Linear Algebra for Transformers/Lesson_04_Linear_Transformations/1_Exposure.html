LESSON 04 — EXPOSURE LAYER

Linear Transformations
The System Changes the Player

How consistent, predictable rules reshape vectors across space — rotating meaning, compressing dimensions, and enforcing the geometry that makes neural networks both powerful and steerable.

01 — THE TWO AXIOMS

What Makes a Transformation Linear

A transformation T is a function that takes a vector in and produces a vector out: T: ℝⁿ → ℝᵐ. It is linear if it satisfies two axioms:

Axiom 1: Additivity

T(v + w) = T(v) + T(w)

Transforming a combination = combining the transformations

Axiom 2: Homogeneity

T(α·v) = α·T(v)

Scaling the input scales the output proportionally

What breaks linearity? Constant shifts (T(0) ≠ 0) and squaring (T(2v) ≠ 2·T(v)). Rotations, scaling, and projections all pass.

Select a transformation type to watch it reshape the entire grid of points. Linear transforms move the grid predictably; non-linear transforms distort it chaotically.
Identity — T(v) = v. No change. Linear ✓

02 — GEOMETRIC TYPES

How Transformer Layers Reshape Meaning

Scaling

T(v) = 3v. Stretches every vector to triple length. Directions stay identical; only magnitude changes. Amplifies or dampens activation strength without changing semantic identity.

Rotation

Rotates every vector by a fixed angle. Lengths perfectly preserved. Changes semantic content ("formal" → "informal") while keeping confidence unchanged. Paper #35 uses this for norm-preserving steering.

Projection

Destructive — drops a vector onto a lower-dimensional subspace. Q, K, V projections compress 768D → 64D, deliberately destroying 704 dimensions to keep only what's relevant for that head's task.

Shearing

Skews the space — dragging one axis while leaving others fixed. Creates oblique outputs from perpendicular inputs. Feed-forward layers implement this to mix information across feature dimensions.

The Null Space

Every transformation has a null space: input vectors mapped to zero. Information in the null space is irretrievably destroyed. W_Q's null space = all features the head's Query simply cannot see.

03 — THE TRANSFORMER LAYER

Linear + Non-Linear Cascade

A single Transformer layer is a cascade of linear and non-linear operations. Without the non-linear steps (Softmax, GELU), 24 stacked layers would collapse into a single linear transformation.

LINEAR

Q = W_Q · x  |  K = W_K · x  |  V = W_V · x

NON-LINEAR

α = softmax(Q·Kᵀ / √d_k)

LINEAR

output = Σ α_j · V_j (linear combination)

NON-LINEAR

h = GELU(W₁ · output)

LINEAR

final = W₂ · h

RESIDUAL

output = input + final

Critical: Non-linearity makes depth meaningful. Each layer computes genuinely new features that no single linear pass could express.

04 — EDGE CASES

Extremes & Invariants

Identity Transformation

T(v) = v. Does nothing. The residual connection is an identity bypass — even if attention produces garbage, the original signal survives via addition: output = v + T(v).

Zero Transformation

T(v) = 0 for all inputs. Technically linear, but information-destroying. The null space = the entire input space. This is what a dead attention head looks like — head pruning exploits it.

Counter-Correction

Inject a steering vector at layer 10; by layer 20 the model rotates the hidden state back toward pre-trained equilibrium. The downstream transformations have an immune system against misaligned interventions.
