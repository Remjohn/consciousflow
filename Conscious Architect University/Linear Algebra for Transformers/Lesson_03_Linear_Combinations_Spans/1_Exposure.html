Linear Combinations
The Mixing Console

How new meaning is manufactured by blending existing vectors at controlled proportions — and the hard geometric walls that define what can never be reached.

01 — THE MIXING CONSOLE

Blending Vectors With Weighted Faders

A linear combination takes a set of existing components, assigns each a scalar weight, multiplies each component by its weight, and sums the results. The output is a new entity that inherits characteristics from every source in exact proportion.

Consider two behavioral primitives: v₁ = (1, 0) (pure Empathy) and v₂ = (0, 1) (pure Logic).

w = α₁ · v₁ + α₂ · v₂

By varying α₁ and α₂, you manufacture composite vectors that never existed as primitives. The fader positions are the weights; the resulting blend is the linear combination.

02 — SPAN: THE GEOMETRIC BOUNDARY

Independence vs Dependence

The span of your source vectors is the set of ALL possible outputs you can generate by varying the weights. It defines the hard geometric limit of what your system can express.

  • 1 vector → span is a line
  • 2 independent vectors → span is a plane (entire 2D)
  • 2 dependent vectors → span collapses to a line
  • 3 independent in 3D → span fills the entire volume
If v₂ = 2·v₁, both point along the same axis. No matter what weights you choose, the output is trapped on one line. The dependent vector is mathematically dead weight.

03 — THE TRANSFORMER CONNECTION

Attention Output = Linear Combination

Every single attention output is a linear combination. The model takes the Value vectors of every relevant token, assigns each a weight (from Softmax), and blends them into a completely new vector.

output = 0.6·V₁ + 0.3·V₂ + 0.1·V₃
= 0.6(1,0) + 0.3(0,1) + 0.1(1,1)
= (0.7, 0.4)

The output (0.7, 0.4) never existed in the vocabulary. It's a freshly minted representation — 70% Empathy-leaning, 40% Logic-leaning. New contextual meaning manufactured from old parts.

Drag the attention weight sliders to redistribute focus across the three value vectors. The blended output shifts in real-time.

04 — EDGE CASES

When the Combination Breaks

All-Zero Weights

Setting every weight to zero produces the zero vector. In attention, this means no token was relevant — a degenerate failure state. Should never occur after proper Softmax normalization, but can emerge from gradient collapse.

Negative Weights

A negative weight steers away from a concept. The CCP computes corrected = state + (-0.5)·e_aggression. You don't define "non-toxic" — you subtract "toxic."

Oversaturated Weights

If α₁=100 and α₂=0.01, the combination degenerates into a copy of v₁. This is the overconfidence failure from Lesson 2 — Softmax concentrates near-100% weight on a single token. The model stops blending and starts parroting.
