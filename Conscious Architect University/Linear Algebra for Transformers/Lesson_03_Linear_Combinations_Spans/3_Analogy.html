01 — UNIVERSAL MAPPING

The 6-Domain System

Tactical Role Composition

Barella's match-day role is not a pure archetype. It is a linear combination of tactical primitives:

Barella = 0.6·Box-to-Box + 0.25·Playmaker + 0.15·Destroyer

Change the weights for a Champions League knockout and Barella shifts to 0.4 B2B + 0.15 Playmaker + 0.45 Destroyer. Same player, same basis — completely different tactical output.

Span: All tactical roles achievable from 3 primitives. Without a genuine creative Number 10 (independent 4th basis), that function is permanently outside the span.

Hybrid Build Construction

Basis vectors are pure archetypes across [Str, Sta, Int, Wis, Cha]:

Battlemage = 0.5·Warrior(10,8,0,0,0) + 0.5·Mage(0,0,10,0,8)
= (5, 4, 5, 0, 4)

A "Spellsword" with stats (5,4,5,0,4) is literally the Battlemage — a dependent vector. Adding it expands nothing.

Span boundary: If all archetypes have zero Dexterity, the Rogue build is unreachable. You need an independent 4th basis.

The Mixing Console

The most literal physical linear combination machine. Each fader = weight. Each stem = basis vector.

Master = 0.7·Bass + 0.5·Drums + 0.8·Vocals + 0.3·Synth + 0.2·Guitar

Two rhythm guitars with identical tone are nearly dependent — mixing both adds negligible content. A lead guitar with a different register is independent.

Span: No strings recorded? No fader manipulation produces strings. That timbre is outside your stem's span forever.

Recipe as Linear Combination

Vinaigrette = 3·Oil + 1·Lemon + 0.5·Mustard + 0.2·Salt

Pantry of flour, butter, sugar → span limited to shortbread, pie crust, cookies. Add eggs (independent vector: protein + emulsification) → span explodes to include cakes, custards, meringues, soufflés.

Dependence trap: Table salt ≈ sea salt ≈ pink salt. Fifty types of salt give you the same span as one.

Group Dynamic Composition

Group = 0.5·CEO(9,8,9,3,2) + 0.3·CTO(7,9,3,5,4) + 0.2·CMO(8,4,10,8,6)
= (8.2, 7.5, 7.4, 4.6, 3.4)

If all 3 have near-zero Neuroticism, the group can never produce high-anxiety dynamics — outside the span. Need a 4th person with independent high Neuroticism.

Break: Emotional contagion is non-linear — one anxious person can infect the entire group far beyond their proportional weight.

CCP Behavioral Composition

Steer = 0.6·e_motivational + 0.25·e_technical + 0.15·e_humorous

RISER (Paper #34) changes weights at every token. Token 5: heavy empathy. Token 20: analytical logic. Token 35: humor activates. Same formula, shifting coefficients.

Span constraint: No "Personal Storytelling" direction extracted? No weight manipulation produces storytelling. You need an independent new primitive.

02 — WHERE LINEARITY BREAKS

Cross-Domain Comparison

🤖 AI: Perfect Linearity

Attention output is rigorously a weighted sum. Softmax guarantees non-negative weights summing to 1. The geometry is mathematically exact.

🎵 Music: Almost Exact

Gain staging (fader volumes) IS linear addition. But compression, distortion, reverb are non-linear transforms that break the model.

🍳 Cooking: Input Only

Ingredient ratios are linear. But sugar + heat ≠ more sugar — it equals caramel. Maillard reactions transform ingredients into qualitatively new molecules.

🧠 Psychology: First-Order

Group composition is a reasonable linear model. But emotional contagion, groupthink, power dynamics are fundamentally non-linear emergent phenomena.

The takeaway: Linear combinations model structural composition. Reality applies non-linear transformations on top. Knowing where the linear model holds — and where it breaks — is the difference between a naive engineer and a Sovereign Architect.

03 — REASONING TRAPS

Logic Puzzles

1. The Phantom Independence

Setup: v₁=(1,0,0), v₂=(0,1,0), v₃=(1,1,0). Are these 3 vectors independent? What dimension is their span?

Dependent. v₃ = v₁ + v₂. Span is 2D (the XY plane). Despite having 3 vectors, the Z-axis is completely unreachable. The third vector is dead weight.
2. The Negative Weight Paradox

Setup: steer = 1.0·e_empathy + (-1.0)·e_aggression. Is this identical to a dedicated "anti-aggression" vector?

No. Subtracting aggression removes that geometric component. But if "anti-aggression" includes positive attributes (patience, tolerance) orthogonal to the aggression axis, a dedicated vector would steer toward those. Subtraction removes; it does not replace.
3. The Convex Hull Trap

Setup: Softmax weights are non-negative, sum to 1. Can the attention output ever lie OUTSIDE the convex hull of value vectors?

No. Non-negative weights summing to 1 = convex combination. Output is geometrically confined inside the convex hull. Steering interventions CAN escape it because they use unconstrained weights.
4. The Rank Collapse

Setup: LoRA rank r=8, but during training 2 of the 8 basis directions converge to near-identical orientations. What's the effective rank?

Effective rank ≈ 6. Two converged directions function as one, collapsing a dimension. The behavioral nuance that required those two directions to be distinct is permanently lost.
