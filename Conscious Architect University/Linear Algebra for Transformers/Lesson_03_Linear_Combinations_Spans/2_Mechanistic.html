01 — ATTENTION OUTPUT PIPELINE

Tracing "She was brave."

Every attention output is a linear combination of all Value vectors, weighted by Softmax scores. Let's trace the complete pipeline for the sentence "She was brave."

1

Value Vector Generation

After W_v projection:
V_She = (0.1, 0.8, 0.3)
V_was = (0.0, 0.1, 0.0)
V_brave = (0.9, 0.2, 0.7)

2

Attention Weights (from Q·K/√d_k + Softmax)

αbrave→She = 0.55, αbrave→was = 0.05, αbrave→brave = 0.40

3

Linear Combination (The Blend)

output = 0.55·(0.1,0.8,0.3) + 0.05·(0.0,0.1,0.0) + 0.40·(0.9,0.2,0.7)
= (0.055,0.44,0.165) + (0.0,0.005,0.0) + (0.36,0.08,0.28)
= (0.415, 0.525, 0.445)
Click each step to highlight it on the pipeline canvas. The output vector borrows 55% from "She" (the referent) and 40% from "brave" (self-attention), manufacturing a blended representation.

02 — THE STEERING EVOLUTION

From Fixed Weights to Language-Driven Coefficients

PAPER #15

WAS — Weighted Activation Steering

h_new = h_old + Σ α_i(x) · e_i

Replaces fixed scalar α with a learned function α(x). A lightweight neural controller reads the input and outputs dynamic weights per steering direction per layer. Same formula — adaptive coefficients.

Angry client → empathy=0.2, firmness=0.9
Calm client → empathy=0.8, firmness=0.3
PAPER #16

HYPERSteer — Language → Coefficients

α = f_hyper("warm, encouraging, metaphorical")

A hypernetwork processes a natural language behavior description and automatically outputs the coefficient vector for combining latent steering directions. No manual tuning required.

Span constraint: If the basis lacks an independent direction for "humor," no text description will produce it.

04 — EDGE CASES & INVARIANTS

Where the Math Constrains You

Rank-Deficient Steering

5 steering vectors, but 3 are linear combinations of the first 2? You have 5 faders but 3 are ghost controls — moving them produces only changes already achievable by the first 2. Effective span = 2D.

LoRA Span Collapse

A rank-4 LoRA update can only modify behavior along 4 independent directions. If the target behavioral shift requires 12 independent directions, the model approximates by projecting onto the closest 4D subspace — losing 8 dimensions of nuance.

Attention Degeneracy

Near-one-hot Softmax (α = [0.99, 0.005, 0.005]) degenerates the combination into a copy. The model stops blending and starts parroting. This is the overconfidence failure that EAST addresses.

Invariant: Zero Vector Inclusion

0 = 0·v₁ + 0·v₂ + ... The zero vector is always in the span. In attention, this corresponds to zero weight on everything — prevented by Softmax normalization.

Invariant: Closure Under Combination

If u and w are both in the span, any combination β₁·u + β₂·w is also in the span. Cascaded attention layers cannot escape the geometric boundary.

Invariant: Dimension Bound

dim(span) ≤ min(k, n). The span never exceeds the number of independent vectors or the ambient space dimensionality. The hard mathematical ceiling on expressiveness.
