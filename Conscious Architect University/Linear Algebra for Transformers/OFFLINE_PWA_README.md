# Offline PWA for Linear Algebra for Transformers

## What This Adds

This folder now includes an installable offline reader for the full `Linear Algebra for Transformers` course.

It works by:

- using the existing handcrafted lesson `.html` files as the primary reading surface
- keeping markdown-only docs available inside the same app
- pre-caching the course files through a service worker so the course keeps working after the first sync

## How To Test Locally

Service workers do **not** work reliably from `file://`.
Serve the folder over HTTP:

```powershell
cd "D:\Work\The Conscious Coaching Factory\Conscious Architect University\Linear Algebra for Transformers"
python -m http.server 8848
```

Then open:

```text
http://localhost:8848
```

## How To Install On Android

1. Serve or deploy this folder so it opens in Chrome on the phone.
2. Open the root page once with internet.
3. Wait until the app says the offline cache is enabled.
4. Use Chrome's `Add to Home Screen` or the in-app install button.
5. Launch it from the home screen.

After the first successful sync, the course should remain readable without internet.

## APK Note

This build is a real offline PWA first.
If you later want an actual Android APK, the clean next step is to wrap this PWA with:

- Capacitor
- Trusted Web Activity
- or a lightweight WebView shell

That is a packaging step on top of this offline foundation, not a different content system.
