The Pipeline Function 𝒫

The Applied Clustering Pipeline is a composite function mapping a raw high-dimensional vector to a discrete cluster label:

𝒫 = 𝒜 ∘ 𝒦 ∘ ℛ ∘ 𝒩 ∘ ℱ ℱ Feature Selection → ℝ¹⁰⁰ to ℝ⁶ (projection onto 6 behavioral axes) 𝒩 Z-Score Normalization → ℝ⁶ to ℝ⁶ (mean 0, variance 1 per feature) ℛ PCA Compression → ℝ⁶ to ℝᴹ (top-M eigenvectors of covariance matrix) 𝒦 K-Means Clustering → ℝᴹ to {1…k} (label + centroid distance) 𝒜 Action Injection → Neo4j write + JIT Compiler constraint load
Prediction Gate 01 — Z-Score Normalization by Hand
Compute the Z-Score normalized values for two clients on the Confrontation Tolerance feature.

Population statistics: μ = 50, σ = 20

Client X: raw value = 90
Client Y: raw value = 10

Formula: z = (x − μ) / σ. Enter both Z-Scores, rounded to one decimal.
Client X — z_X
Client Y — z_Y

Correct. Client X: z = (90−50)/20 = +2.0. Client Y: z = (10−50)/20 = −2.0. They now sit at equal and opposite distances from the population center — the algorithm can distinguish them.

The Z-Score formula is not arbitrary. The denominator σ is the natural unit of spread for the population. Dividing by it guarantees that a one-unit difference on any normalized feature contributes identically to Euclidean distance. Without it, one axis dominates by a factor proportional to its raw range.

Critical: the normalization parameters μ and σ must be stored after initial fitting. Every new client entering the system is normalized using the same stored statistics — not re-fit on the current batch. Recomputing on each new client would contaminate the normalization and shift previously assigned Z-Scores.

Misconception Trap — Guardian Agent Drift Detection
The Guardian Agent monitors cluster health weekly. A developer proposes this alert rule:

"Fire a Concept Drift alert whenever the WCSS drops sharply from the previous week."

Is this a valid drift detection mechanism? Select the answer that correctly diagnoses the problem.

Why Silhouette and not WCSS: WCSS is an absolute measure. It decreases whenever any point moves closer to its centroid — which happens naturally as more clients settle into behavioral patterns. WCSS tells you nothing about whether a client could plausibly belong to a different cluster instead.

Silhouette is a relative measure. It compares each point's cohesion (average distance to members of its own cluster) against its separation (average distance to members of the nearest competing cluster). A falling Silhouette means points are moving toward the boundaries — they're becoming ambiguously assigned. That is the precise mathematical signature of Concept Drift.

Drift alert fires when: s̄ₜ < 0.40 OR (s̄_baseline − s̄ₜ) / s̄_baseline > 0.15

Correct. Rolling average = (0.72 + 0.71 + 0.73 + 0.70) / 4 = 0.715. Relative drop = (0.715 − 0.52) / 0.715 = 0.273 = 27.3%. This exceeds the 15% threshold, so the drift alert fires.

But the absolute check: 0.52 > 0.40 — the score has not hit the absolute floor. Investigation reveals the new clients have short interaction histories and cluster near boundaries. The incumbent clients maintain Silhouette > 0.70. Verdict: demographic influx, not genuine drift. The centroids are intact.
